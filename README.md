
# NASA Space Quiz

## Project Idea
A simple quiz about NASA missions and the solar system. It helps NASA by
raising public interest in space and teaching students about its work.

## Technologies / Tools
- Markdown
- Git and GitHub (issues, branches, pull requests)

## How to Use
1. Open `quiz/questions.md` and answer the questions.
2. Check your answers in `quiz/answers.md`.
3. Count your score out of 6.
